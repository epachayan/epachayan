## Projects

| | |
|---|---|
| [voynich-transfer](https://github.com/epachayan/voynich-transfer) | A reproducible metric for structural similarity between regions of an undeciphered text, applied to the Voynich Manuscript. 21 preregistered experiments, Python + NumPy only. Not a decipherment — a measurement any future theory has to explain. |
| [indus-script](https://github.com/epachayan/indus-script) | Machine-readable catalogues of 1,269 Mohenjo-daro/Harappa seals (Mackay + Marshall), 531 plate-codings, and 90 held-out validated constraints, with a pipeline comparing Indus sign sequences against Sumerian, Egyptian, and Linear A/B. No decipherment claimed — results are largely negative and corrections are kept in place, not deleted. |
| [tallystick](https://github.com/epachayan/tallystick) | An adversarial harness for accountability in delegated AI agent action: 850 scenarios, 34 adversarial classes, 18 adjudication baselines. Finds a conservation boundary — evidence-based mechanisms can resolve *whether* a party diverged from the record, never *why*, at no extra cost. |
| [macrocanary](https://github.com/epachayan/macrocanary) | A public macro-risk dashboard that doubles as a privacy-minimized bot-detection canary. Real traffic, honeypot telemetry, and retrospective fleet-level campaign analysis on Cloudflare Pages/Workers/D1. [Live](https://macrocanary.pages.dev) |
| [LocalGuard](https://github.com/epachayan/LocalGuard) | A plant-inspired host IDS for air-gapped environments: hybrid heuristics + offline ONNX ML in C#/.NET, watching files and the Windows Registry for persistence and anomalies. |
